# Lion Racing League – Webseite & Server

Dieser Bereich bündelt die öffentliche Liga-Webseite, das Admin-Panel und die Server/API-Schicht.

- Frontend: `apps/web`
- Backend/API: `apps/api`
- Gemeinsame Domäne, Scoring- und Berechtigungspakete: `packages/`
- Start lokal: `npm run dev` und `npm run api`

Die Webseite ist für die öffentliche Darstellung, Live-Timing, Tabellen, Regelwerk, Bewerbungen und geschützte Admin-/Fahrer-/Team-Bereiche zuständig.
